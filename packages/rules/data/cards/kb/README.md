## 주요 특징
- WE:SH 시리즈: 일상 소비 전반을 커버하는 할인형 카드, 마이위시는 서비스팩 선택으로 맞춤 혜택 제공
- 톡톡 시리즈: 젊은 층 타겟의 실속형 카드, 낮은 전월실적에 높은 할인율
- Easy 시리즈: 맞춤형 할인 카드, Pick/On/All 세 가지 타입으로 소비 패턴에 맞춰 선택 가능
- 위시올: 전월실적 없이 국내 1% 할인 제공하는 범용 카드
- K패스 카드: 대중교통 10% 할인 + K패스 환급 이중 혜택
- 노리2 체크카드: 연회비 무료 체크카드로 커피/편의점 할인 제공
- 굿데이카드: 주유/교통/통신/외식 할인의 올라운드 생활 카드, 연간 100만원 이용 시 차년도 연회비 면제
- 다담카드: 교통/통신/주유 기본 할인 + 적립팩 선택으로 맞춤 혜택, 아파트관리비/공과금도 실적 인정
- 스카이패스 티타늄: 대한항공 마일리지 적립 특화, 무실적 기본 적립 + 해외 2배 적립
