# Plan 80 — Cycle 3 Publication, Runtime, and Dependency Boundaries

**Findings:** C3-008, C3-009, C3-010, C3-011, C3-012, C3-013, C3-014
**Deploy mode:** none
**Status:** completed

## Outcome

Give every published catalog byte set a unique identity, make web and default
CLI analysis consume the same compiled runtime contract, move heavy CSV work
off the UI thread, fail closed on incomplete scraper input, and authenticate or
remove every runtime dependency.

## Tasks

- [x] Build all normalized summary/optimizer/detail/category payloads without
  identity first, compute a deterministic publication ID from the keyed
  serialized payload set (or an automatically derived equivalent contract
  revision), then inject the ID into every artifact and shard.
- [x] Add source-stable/projection-changed and mixed-old/new tests proving that
  changed generated bytes change identity and cannot be combined in one page
  session.
- [x] Add one schema-validating optimizer-artifact reader owned by
  `@cherrypicker/rules`. Use the compiled artifact for default CLI
  optimize/report; retain recursive YAML loading only for an explicit
  `--cards` authoring override and clearly disclose that mode.
- [x] Transfer the original CSV `ArrayBuffer` to the parser worker. Perform
  encoding detection, decoding, replacement counting, bank detection, and CSV
  parsing there, returning warnings/metadata with the result and avoiding
  string structured-cloning.
- [x] Replace scraper source truncation with a completeness-preserving policy.
  This cycle may chunk/merge with validation or reject over-limit source before
  the model call; it must expose original/sent sizes and cannot write an
  ordinary success artifact after omission.
- [x] Declare Zod directly in the scraper workspace and add a dependency
  boundary check for undeclared non-relative production imports.
- [x] Replace the URL-only SheetJS resolution with a content-authenticated,
  reproducible source while preserving the supported API/version behavior:
  an integrity-bearing immutable package, or a vendored immutable archive with
  a checked SHA-256/SHA-512 and a blocking lock-policy gate. Frozen install
  alone is not sufficient.
- [x] Remove the seven unused direct declarations (`@cherrypicker/viz`,
  LayerChart, three direct D3 packages, Papa Parse, and parser `unpdf`) and
  regenerate the lockfile. Add explicit exemptions only for real config/CLI
  consumers.

## Acceptance

- [x] Holding YAML/taxonomy data constant while changing a projection changes
  the publication ID and mixed artifacts fail closed.
- [x] Default CLI and web load the same normalized optimizer graph; a
  fresh-process CLI regression stays within an explicit startup/RSS budget.
- [x] Maximum-size CSV preprocessing does not execute on the browser main
  thread and the worker owns the transferred buffer.
- [x] A 40,001-character scraper source cannot yield an undisclosed successful
  catalog write.
- [x] Every production import is directly declared and every remote dependency
  is content-authenticated.
- [x] Data build/check, dependency policy, parser/web tests, bundle budgets,
  lint, typecheck, and build pass.
